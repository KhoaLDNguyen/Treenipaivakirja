# Treenipäiväkirja 📱

Mobiilisovellus harjoitusten kirjaamiseen ja seurantaan. Toteutettu Haaga-Helian Mobiiliohjelmointi-kurssin lopputyönä.

## Ominaisuudet

- Harjoitusten lisäys, muokkaus ja poisto
- Liikkeiden kirjaaminen sarjoineen, toistoineen ja painoineen
- Valmiit harjoitusohjeet (kuntosali ja juoksu)
- Harjoitusohjeiden linkitys suoraan päiväkirjaan
- Tilastot: treenikerrat, tunnit, suosituin liike, viikoittainen kaavio
- Haku lajeittain

## Teknologiat

| Teknologia | Käyttötarkoitus |
|---|---|
| React Native + Expo | Mobiilisovelluskehitys |
| expo-router | Näyttöjen välinen navigointi |
| expo-sqlite | Paikallinen tietokanta laitteella |
| react-native-chart-kit | Tilastokaaviot |
| @react-native-community/datetimepicker | Päivämäärän valinta |

## Asennus ja käynnistys

```bash
npm install
npx expo start
```

Avaa sovellus Expo Go -sovelluksella mobiililaitteellasi.
